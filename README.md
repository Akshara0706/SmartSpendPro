# 💰 SmartSpend Pro

SmartSpend Pro is a sleek, single-page progressive web application (PWA) designed to track income, manage personal expenses, and visualize financial health with complete data privacy. 

Built purely using vanilla JavaScript, modern CSS, and HTML5, the app keeps your financial data entirely on your machine via LocalStorage—meaning zero server-side tracking, zero accounts to create, and maximum privacy.

## ✨ Features

* **📊 Real-time Analytics:** Interactive doughnut charts using `Chart.js` to visually break down expenses by custom parameters over days, weeks, or months.
* **🐻 Multiple UI Themes:** Seamlessly toggle between Light Mode, a cozy Bear Mode layout, and Midnight Dark Mode.
* **🚨 Smart Budget Alerts:** Live tracking of a custom monthly limit with automated visual warnings when approaching or crossing thresholds.
* **🎨 Dynamic Categories:** Built-in templates with the ability to add and delete tailored income/expense categories with a built-in emoji selector.
* **📤 Ledger & Data Export:** Filter and search through transaction history effortlessly, or export data instantly into clean CSV files.
* **🔒 Secure & Private:** 100% offline-first local state management powered by `LocalStorage`.

## 🛠️ Tech Stack

* **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS Variables
* **Libraries:** [Chart.js](https://www.chartjs.org/) for data rendering
* **Fonts:** Google Fonts (Nunito & Space Mono)
